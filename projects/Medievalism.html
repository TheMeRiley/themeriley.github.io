Medievalism

An open-world survival game set in a medieval world. This is a work in progress.

Overview

Medievalism is an open-world survival game set in a medieval world. Players can explore a vast landscape, gather resources, craft items, and engage in combat with various enemies.

Features

  • Open-world exploration
  • Resource gathering and management
  • Crafting systems
  • Combat mechanics

Progress

The game is currently in development, with the core mechanics implemented and the world map partially designed.

Future Plans

Future updates will include additional biomes, more crafting options, and expanded storyline content.
